# PsychonautWiki Journal — sideload build

Signing-ready build of the final archived GPL-3.0 iOS source edition (version 11.11).

The repository workflow builds an unsigned IPA for personal sideloading. Journal data remains stored locally on the device. This project is not the later proprietary/premium release and is not affiliated with or endorsed by PsychonautWiki or the original developer.

See `PsychonautWiki-Journal-Sideload-Source.zip` for the complete source package and retained GPL-3.0 license.
